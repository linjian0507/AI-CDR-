# AI 矢量助手 —— CorelDRAW AI 插件

AI 矢量助手是一个运行在 Windows + CorelDRAW 中的 AI 辅助设计插件。它可以通过文字提示词或参考图片生成 SVG，解析 SVG 中的分组并导入 CorelDRAW；也可以调用图片模型进行生图、改图、放大、去字、提取主体等处理，再把结果导入 CDR 或交给本地描摹工具转成可编辑矢量。

本仓库发布的是 **v2.3.1** 当前版本，包含：

- 自动检测 CorelDRAW 安装位置的 Windows 安装程序；
- CorelDRAW 原生插件源码；
- 已编译的安装程序；
- 不包含开发机上的 API Key、模型参数、生成历史、生成图片和个人配置。

> 当前版本已经移除 SuperSVG。现在的图片转矢量方案只有 CorelDRAW 内置 PowerTRACE 和离线 VTracer，选择 VTracer 后可以继续选择它自己的预设模式。

## 一、主要功能

### 1. AI 生成分层 SVG

在「SVG 矢量」页输入提示词，插件会要求模型返回带分组的 SVG。生成完成后：

1. 在预览区查看结果；
2. 在图层列表中查看模型返回的分组；
3. 取消勾选不需要的图层；
4. 点击「导入勾选图层」；
5. 插件把 SVG 导入当前 CDR 文档，并按 SVG 分组拆成独立 CDR 图层。

推荐提示词结构：

```text
主体 + 场景 + 构图 + 风格 + 配色 + 图层要求
```

示例：

```text
一只卡通橘猫坐在月亮上钓星星，深蓝夜空，黄色星星，
扁平插画风格，画面干净，分为背景、月亮、橘猫、鱼竿、星星五个 SVG 图层。
```

### 2. SVG 风格和模板

内置 SVG 风格包括：

- 不指定风格；
- 扁平插画；
- 极简线稿；
- 国潮插画；
- 儿童卡通；
- 几何图形；
- 复古海报；
- 科技图标。

内置模板可以快速填入常用题材，例如 Logo、风景插画、咖啡店招牌、国潮锦鲤、科技感图标、生日贺卡和节日边框。模板不是固定图片，而是提示词起点，选中后可以继续修改文字。

### 3. 参考图生成 SVG

SVG 页支持三种参考图模式：

- **无参考**：只根据提示词生成；
- **临摹还原**：尽量保持参考图的内容和构图；
- **风格参考**：参考配色、构图和视觉风格，但允许重新创作。

可以点击「选择参考图」，也可以把图片拖到参考图区域。已有参考图时，提示词可以只写补充要求。

### 4. AI 生图和 AI 改图

在「AI 生图」页可以：

- 根据提示词生成图片；
- 选择已有图片后进行编辑；
- 选择 CDR 中当前选中的对象作为来源；
- 把生图结果导入 CDR；
- 把生图结果设置为 SVG 参考图；
- 对生成图片进行 PowerTRACE 或 VTracer 描摹。

支持的生图路由：

- **自动路由**：根据模型名称和是否有来源图片自动选择；
- **图像接口**：适用于 `gpt-image`、DALL·E、Imagen 等有 `/images` 接口的模型；
- **对话接口**：适用于在 Chat Completions 中返回图片 URL 或 Base64 的视觉模型。

如果模型与路由不匹配，插件会停止请求并提示改用正确路由，避免把图像模型错误发送到普通对话接口。

### 5. 图片预设

当前版本保留以下图片处理预设：

- 不用预设；
- 糊转清晰；
- 文本还原；
- 拆分元素；
- 拆分海报；
- 融合海报；
- 横版转竖；
- 竖版转横；
- 比例扩图；
- 提取主体；
- 提取背景；
- 去掉文字；
- 转线稿图；
- 修老照片；
- 转电子版；
- 去布纹理；
- 产品精修；
- 菜品补齐；
- 转二维图；
- 高清放大；
- 转矢量图（PowerTRACE 描摹）。

预设会填入一段基础提示词，下面的编辑框可以继续追加要求。预设不是保证文字 100% 正确的 OCR 工具，海报小字、复杂品牌字和密集排版建议分块处理或后期在 CDR 中重新录入。

### 6. 两种图片描摹方案

#### CorelDRAW PowerTRACE

直接调用当前 CDR 内置的 PowerTRACE。它通常适合：

- 轮廓清晰的二维图；
- Logo；
- 扁平插画；
- 颜色块明确的图形；
- 已经经过「转二维图」处理的图片。

PowerTRACE 依赖 CDR 当前版本的 COM 对象模型，描摹过程在 CDR 内部完成。

#### VTracer

VTracer 是随插件分发的本地离线程序，不需要上传图片。当前保留三个模式：

1. 默认彩色 Logo / 扁平插画；
2. 黑白 / 线稿；
3. 照片 / 多色图 / 油画素材。

使用方法：

1. 在「描摹方案」选择「VTracer（离线描摹）」；
2. 在出现的「VTracer 预设」中选择模式；
3. 点击「描摹并导入」；
4. 插件在临时目录生成输入文件；
5. 调用插件目录中的 `tools\vtracer\vtracer.exe`；
6. 读取生成的 SVG 并导入 CDR。

VTracer 适合颜色和轮廓明确的图片，不适合直接把复杂照片转换成大量精细可编辑对象。复杂图片建议先使用「转二维图」、降低颜色过渡，再描摹。

## 二、最快安装方法

### 1. 下载安装包

进入本仓库的 `release` 目录，下载：

```text
AI矢量助手-v2.3.1-安装包.zip
```

解压后得到：

```text
AI矢量助手-安装程序-v2.3.1.exe
```

也可以直接运行仓库中提供的同名 `.exe`。

### 2. 以管理员身份运行

右键安装程序，选择「以管理员身份运行」。安装程序需要向 CorelDRAW 的 `Programs` / `Programs64` 目录写入插件文件，因此建议始终使用管理员权限。

安装前请关闭所有 CorelDRAW 窗口。程序会主动检查 `CorelDRW.exe` 是否运行，运行时不会继续安装。

### 3. 选择 CDR 版本

安装程序会自动检查：

- 当前用户注册表；
- 本机注册表 32 位视图；
- 本机注册表 64 位视图；
- CorelDRAW 注册表中的 `ProgramsDir`；
- 注册表中的 `ConfigDir` 推导路径；
- 常见 Program Files/Corel 目录。

只有真正找到 `CorelDRW.exe` 的目录才会显示为可安装版本。列表可能显示：

```text
X4 32位
2018 64位
2022 64位
```

版本数量取决于电脑实际安装情况，不是固定写死的。

操作步骤：

1. 查看自动扫描出的版本；
2. 取消勾选不需要安装的版本；
3. 保留需要安装的版本；
4. 点击「安装」。

如果列表为空：

1. 确认 CorelDRAW 已经安装；
2. 点击「重新扫描」；
3. 确认 `CorelDRW.exe` 没有被杀毒软件隔离；
4. 如果是绿色版或特殊目录版，可以把 CorelDRAW 的 `Programs` 或 `Programs64` 目录加入注册表后再扫描；
5. 也可以手动把插件运行文件复制到目标 CDR 的 `Programs...\Addons\AIVectorHelper`，但优先使用安装程序。

### 4. 安装时不会覆盖现有模型参数

这是本版本的重点：

- 安装包中没有 `config.json`；
- 安装包中没有 `history.json`；
- 安装包中没有 `svg-history.tsv`；
- 安装包中没有 API Key；
- 安装时只覆盖插件 DLL、XSLT、addon 文件和 VTracer；
- 目标目录已有的 `config.json`、`svg-history.tsv`、`output` 不会被复制覆盖；
- 旧版残留的 `tools\supersvg` 会在安装时删除。

因此，安装这个发布包不会把开发机的模型参数带到用户电脑，也不会把当前 CDR 正在使用的模型参数替换掉。

### 5. 卸载插件

1. 关闭 CorelDRAW；
2. 以管理员身份运行安装程序；
3. 勾选需要删除插件的 CDR 版本；
4. 点击「卸载选中」；
5. 确认提示。

卸载会删除选中版本的 `Addons\AIVectorHelper` 插件目录，包括该目录中的运行文件、VTracer 和本地配置/历史记录。卸载前如果还要保留模型参数，请先备份：

```text
config.json
svg-history.tsv
```

一键卸载只处理选中的 CDR 版本，不会删除其他版本的插件。

## 三、首次启动

本版本采用 **CorelDRAW 原生 Addon 插件方式**，不使用 VBA/GMS 宏，也不需要导入 `.bas` 文件或手动把宏拖到工具栏。

安装完成后：

1. 完全退出 CorelDRAW；
2. 重新启动 CorelDRAW；
3. 由 `CorelDrw.addon` 加载 `AIVectorHelper.dll`；
4. 在 CorelDRAW 的插件/Addon 面板中打开「AI 矢量助手」；
5. 看到三个页签即表示插件加载成功：

```text
SVG 矢量
AI 生图
模型设置
```

PowerTRACE 也直接通过 CDR 对象模型调用，不依赖 GlobalMacros。CDR 选中对象获取、图片导入和描摹全部由原生插件完成。

### 检查插件是否成功加载

打开插件后应能看到三个页签：

```text
SVG 矢量
AI 生图
模型设置
```

如果插件没有出现或只显示错误信息：

1. 关闭插件面板；
2. 关闭 CorelDRAW；
3. 确认安装到了当前使用的 `Programs` 或 `Programs64`；
4. 确认 CDR 和插件权限一致；
5. 重新启动 CDR；
6. 确认安装目录中的 `CorelDrw.addon` 没有被安全软件隔离；
7. 查看插件目录中的日志。

## 四、模型配置教程

### 1. 新建模型档案

进入「模型设置」页，点击添加模型档案，然后填写：

| 字段 | 说明 |
|---|---|
| 模型名称 | 仅用于本地识别，例如“我的视觉模型” |
| 接口类型 | `openai` 或 `anthropic` |
| API 地址 | 接口服务的 Base URL |
| SVG 模型 | 用于生成 SVG 的模型名 |
| 生图模型 | 用于图片生成的模型名，可以留空 |
| API Key | 你自己的密钥 |
| 支持参考图 | 使用视觉模型时勾选 |

### 2. OpenAI 兼容接口

OpenAI 兼容服务通常填写：

```text
API 地址: https://你的服务地址/v1
接口类型: openai
SVG 模型: 服务实际提供的模型名
```

不要把示例地址、示例模型名或他人的 Key 直接当成可用配置。模型名必须以服务商实际返回的 `/models` 列表为准。

填写后点击「获取模型列表」，如果接口支持模型列表，插件会把可用模型放入下拉框。然后点击「保存模型设置」。

### 3. Anthropic 接口

接口类型选择 `anthropic`，填写服务商提供的 Base URL、模型名和 Key。插件会使用 Anthropic 的消息接口和鉴权头。

### 4. API Key 的保存位置

第一次保存后，配置通常保存在插件目录：

```text
<CDR Programs 或 Programs64>\Addons\AIVectorHelper\config.json
```

API Key 以本地配置文件形式保存。不要把这个文件上传到 GitHub、发到群里或提交到 Issue。

本仓库的 `.gitignore` 已经忽略了：

```text
config.json
history.json
svg-history.tsv
output/
```

### 5. 网络代理

如果接口需要代理，在「模型设置」中填写代理，例如：

```text
127.0.0.1:7890
```

不需要代理时保持为空。插件会优先使用 .NET HTTP 请求，失败时尝试调用 Windows 自带的 `curl.exe` 作为备用通道。

### 6. 测试连接

保存模型后点击「获取模型列表」或「测试连接」：

- 成功：可以看到可用模型数量；
- 失败：先看 API 地址是否多写/少写 `/v1`；
- 401/403：检查 Key；
- 404：检查 Base URL 和接口兼容性；
- 模型不支持：检查模型名和所选接口；
- 超时：检查网络、代理、服务端额度。

## 五、SVG 矢量工作流

### 步骤 1：准备模型

在 SVG 页上方选择一个已经保存的模型档案。没有模型档案时，先到「模型设置」添加。

### 步骤 2：填写提示词

建议明确写出：

- 画面尺寸和方向；
- 主体数量；
- 主体位置；
- 背景；
- 配色；
- 风格；
- 是否需要文字；
- 图层名称和数量；
- 是否允许透明背景。

示例：

```text
竖版儿童节海报，浅蓝背景，中央是一只举着气球的小熊，
顶部留出标题区域，底部留出日期区域，扁平卡通风格，
颜色不超过八种，分为背景、标题区、小熊、气球、装饰、底部信息六个图层。
```

### 步骤 3：选择风格和参数

- 选择 SVG 风格；
- 设置方案数；
- 设置创意度；
- 设置图层数量；
- 必要时指定主色或色系；
- 需要透明素材时勾选透明背景。

方案数越多，通常消耗越多 Token，生成时间也更长。一般先用 1 个方案测试提示词，确定方向后再改成 2～3 个方案。

### 步骤 4：使用参考图

选择参考图后，在参考模式中选择：

- 临摹还原：适合希望保持构图的图片；
- 风格参考：适合只借鉴风格；
- 无参考：不使用图片。

提示词可以留空，也可以写补充要求。例如：

```text
保留人物姿势和整体构图，去掉原图中的文字，改为蓝橙配色。
```

### 步骤 5：生成、检查、导入

生成完成后：

1. 查看 SVG 预览；
2. 查看图层列表；
3. 取消勾选不需要的图层；
4. 点击「导入勾选图层」；
5. 在 CDR 的对象/图层泊坞窗中检查结果。

如果勾选「生成完成后自动导入 CDR」，生成完成会自动导入；第一次使用建议关闭自动导入，先检查 SVG。

### 步骤 6：导入失败时排查

如果提示无法连接 CorelDRAW：

1. 确认当前有打开的 CDR 文档；
2. 确认 CDR 没有卡死；
3. 到「模型设置」检查 CDR ProgID；
4. 点击「诊断 CDR 连接」；
5. 确认 CDR 和插件权限一致；
6. 必要时以管理员身份重新注册：

```text
"<CorelDRAW安装目录>\Programs64\CorelDRW.exe" /RegServer
```

32 位版本把 `Programs64` 改为 `Programs`。

## 六、AI 生图、改图和 CDR 选中对象

### 1. 直接生图

1. 进入「AI 生图」页；
2. 选择模型档案；
3. 填写图像模型；
4. 选择分辨率；
5. 在图片提示词框中填写要求；
6. 选择「自动路由」；
7. 点击生成。

生成结果会显示在「生成结果」区域，并保存到插件目录的 `output` 文件夹。发布安装包不带任何历史输出，第一次安装后会自动创建运行目录。

### 2. 选择来源图片

点击「选择来源图片」后，可以对本地图片进行处理。也可以把图片拖入来源图片区域。

选择来源图片后，插件会根据当前预设和补充描述调用图片编辑接口，而不是无来源直接生图。

### 3. 从 CDR 选中对象获取

这是处理海报、局部图形和 CDR 中已有对象时最重要的步骤：

1. 在 CDR 中打开文档；
2. 用选择工具选中一个或多个对象；
3. 如果要处理整张海报，先把海报对象群组或选中海报整体；
4. 回到插件，点击「从 CDR 选中对象获取」；
5. 等待状态栏显示“已从 CDR 选中对象获取来源图片”；
6. 检查来源图片预览；
7. 选择预设；
8. 在补充描述中写明确要求；
9. 点击「生成/编辑图片」。

如果没有实际选中对象，插件会提示先选择对象，不会继续使用旧的来源图片。若要避免把多个无关对象一起处理，先在 CDR 中只选中本次需要的内容。

### 4. 常用预设的正确用法

#### 糊转清晰

适合：

- 图片模糊；
- 大字和主体比较清楚；
- 想尽量保持原构图。

不适合：

- 需要逐字准确重建的密集小字海报；
- 需要严格可编辑文字的场景；
- 需要自动拆分成真正图层的场景。

#### 文本还原

适合文字区域较少的图片。文字很多时，建议先裁剪文字区域，分块处理，然后在 CDR 中重新录入文字。

#### 拆分海报

这个预设是把背景、文字、主体和配图平铺输出为一张辅助图，并不是自动生成真正的 CDR 分层文件。输出结果仍然需要人工检查和抠图/重排。

#### 转二维图

适合先把照片、阴影、渐变较多的图片变成颜色更明确的二维风格，再交给 PowerTRACE 或 VTracer。

#### 转矢量图（PowerTRACE 描摹）

这个预设不调用 AI，直接走 CDR 内置 PowerTRACE。轮廓清晰、颜色块明确时优先使用。

## 七、图片转矢量详细教程

### 方案 A：PowerTRACE

推荐流程：

1. 先生成或导入图片；
2. 如果图片偏写实，先执行「转二维图」；
3. 在「描摹方案」选择 `CorelDRAW PowerTRACE（CDR 内置）`；
4. 点击「PowerTRACE 描摹并导入」；
5. 等待 CDR 完成描摹；
6. 检查颜色数量、轮廓和节点数量；
7. 需要时在 CDR 中取消组合、简化节点或重新填色。

### 方案 B：VTracer

推荐流程：

1. 先把图片处理成颜色块明确的二维图；
2. 选择 `VTracer（离线描摹）`；
3. 选择 VTracer 预设；
4. 点击「VTracer 描摹并导入」；
5. 等待本地程序结束；
6. 检查导入结果。

VTracer 预设选择：

| 预设 | 适合素材 | 结果倾向 |
|---|---|---|
| 默认彩色 Logo / 扁平插画 | Logo、贴纸、扁平插画 | 彩色区域和轮廓平衡 |
| 黑白 / 线稿 | 黑白稿、线稿、剪影 | 颜色更少、轮廓更突出 |
| 照片 / 多色图 / 油画素材 | 多色图片、油画类素材 | 保留更多颜色，但节点可能增加 |

常见质量问题：

- 直接描摹复杂照片会得到很多碎片；
- 渐变和阴影会变成大量路径；
- 文字太小会丢失或变形；
- 背景和主体颜色接近时容易粘连；
- 透明背景不等于自动去背景。

改善方法：

1. 先裁剪主体；
2. 使用「转二维图」；
3. 减少颜色过渡；
4. 选择黑白或默认模式；
5. 放大源图再描摹；
6. 在 CDR 中进行节点简化。

## 八、版本兼容和安装目录

安装程序不会把插件固定装到某一个开发机路径，而是根据检测结果把文件复制到选中版本的：

```text
<CDR Programs 或 Programs64>\Addons\AIVectorHelper
```

插件目录主要文件：

```text
AIVectorHelper.dll       CDR 主面板插件
AIVectorCore.dll         AI 请求、配置和 SVG 核心逻辑
Newtonsoft.Json.dll      JSON 依赖
CorelDrw.addon           CDR addon 加载文件
AIVectorLauncher.cpg     CDR 启动配置
AppUI.xslt               CDR UI 描述文件
UserUI.xslt              CDR UI 描述文件
tools\vtracer\vtracer.exe
```

不同版本 CDR 的 `Programs` 目录名称可能不同：

- 32 位通常是 `Programs` 或 `Programs32`；
- 64 位通常是 `Programs64`；
- 绿色版可能没有标准注册表项。

安装程序只列出真正找到 `CorelDRW.exe` 的目标，避免把文件复制到不存在的目录。

## 九、常见问题

### Q1：安装程序没有找到我的 CDR

点击「重新扫描」。如果仍然没有找到：

1. 找到 CDR 实际安装目录；
2. 确认里面存在 `CorelDRW.exe`；
3. 确认路径下有 `Programs` 或 `Programs64`；
4. 用管理员身份运行安装程序；
5. 对绿色版/精简版，可能需要手动注册 COM 或手动安装插件。

### Q2：安装后插件没有显示

安装程序直接部署原生 Addon，不需要导入宏、不需要设置 GlobalMacros，也不需要把按钮拖到工具栏。

### Q3：安装后原来的 API 配置不见了

正常安装不会覆盖目标目录已有的 `config.json`。如果配置不见，通常是：

- 选择了另一个 CDR 版本；
- 之前手动删除过插件目录；
- 使用了卸载功能；
- CDR 实际使用的是另一个 `Programs`/`Programs64`；
- 配置文件被安全软件隔离。

### Q4：生图报“模型不支持”

检查：

- 模型名称是否为服务商实际支持的名称；
- 图像模型是否使用了图像接口；
- 视觉对话模型是否选择了对话接口；
- 不要把普通聊天模型填到图像接口；
- 不要把只支持图片接口的模型强行走 Chat Completions。

### Q5：生图没有按提示词做，自己添加了文字

图片模型可能会自动补充海报文字。可以：

1. 在提示词中明确写“不要添加任何文字”；
2. 使用「去掉文字」或「转电子版」等预设；
3. 把文字区域单独处理；
4. 最终文字在 CDR 中重新排版，不要完全依赖图片模型。

### Q6：CDR 选中对象获取失败

确认：

1. CDR 文档处于前台；
2. 选择工具确实选中了对象；
3. 对象没有被锁定；
4. 选中后再点击「从 CDR 选中对象获取」；
5. 不要在没有选择对象时直接点击；
6. 复制完成后查看插件中的来源图预览。

### Q7：VTracer 失败或没有生成 SVG

检查插件目录是否存在：

```text
tools\vtracer\vtracer.exe
```

如果是自己复制源码运行，确认使用的是发布包中的 `vtracer.exe`，不要把 `supersvg` 目录或旧版本路径混进配置。复杂图片先降低颜色复杂度。

### Q8：导入后图层顺序不对

在 SVG 页勾选或取消「反转拆分图层顺序」，再导入一次。不同 CorelDRAW 版本对导入顺序的表现可能不同。

### Q9：插件面板显示空白或加载失败

优先检查：

- CorelDRAW 位数与插件目标是否匹配；
- 插件文件是否完整；
- `AIVectorCore.dll`、`Newtonsoft.Json.dll` 是否在同一目录；
- CDR 是否被安全软件隔离了 `.addon`；
- CDR 和插件是否使用相同权限启动。

## 十、源码构建

### 环境

- Windows；
- .NET Framework 4.8 Developer Pack；
- .NET SDK 6/8；
- CorelDRAW；
- 可访问 NuGet；
- 编译插件主项目时，需要当前 CDR 的 `Corel.Interop.VGCore.dll`。

### 构建主插件

仓库源码位于：

```text
src/CDR原生插件-C方案/
```

设置当前 CDR 的 Programs 目录：

```powershell
$env:CORELDRAW_PROGRAMS_DIR = 'C:\Program Files\Corel\CorelDRAW Graphics Suite 2024\Programs64'
```

或者直接传 MSBuild 参数：

```powershell
dotnet build `
  .\src\CDR原生插件-C方案\src\AIVectorHelper.csproj `
  -c Release `
  -p:CorelProgramsDir='C:\Program Files\Corel\CorelDRAW Graphics Suite 2024\Programs64'
```

编译输出在：

```text
src/CDR原生插件-C方案/src/bin/Release/
```

### 构建安装程序

```powershell
dotnet build .\installer\AIVectorInstaller.csproj -c Release
```

安装程序项目会把 `installer\payload.zip` 嵌入到 EXE 中，因此发布前需要先更新 payload：

1. 编译主插件；
2. 把干净的 DLL 和运行文件复制到 `installer\payload\AIVectorHelper`；
3. 确认 payload 中没有 `config.json`、`history.json`、`svg-history.tsv`、API Key、生成结果；
4. 重新压缩 `payload\AIVectorHelper` 的内容到 `installer\payload.zip`；
5. 再编译安装程序。

payload 的正确目录结构是：

```text
tools/vtracer/vtracer.exe
AIVectorCore.dll
AIVectorHelper.dll
AIVectorLauncher.cpg
AppUI.xslt
CorelDrw.addon
Newtonsoft.Json.dll
UserUI.xslt
```

压缩包根目录不能再多套一层 `AIVectorHelper`，否则安装程序会把文件复制到错误的嵌套目录。

### 本地 smoke test

安装器内置 payload 提取逻辑。发布前应至少检查：

- 目标目录原有 `config.json` 不被覆盖；
- 目标目录原有 `svg-history.tsv` 不被覆盖；
- 旧 `tools\supersvg` 会被清理；
- `AIVectorHelper.dll` 被复制到 `Addons\AIVectorHelper` 根目录；
- payload 内没有用户配置和 API Key。

## 十一、仓库安全约定

绝对不要提交以下内容：

```text
config.json
history.json
svg-history.tsv
output/
logs/
任何包含 API Key 的截图
任何包含真实 Base URL + API Key 的配置导出
```

如果 API Key 曾经出现在截图、日志或公开仓库中，应立即在对应服务商后台撤销并重新生成。

本仓库的安装包采用“无用户参数发布”原则：安装包只包含运行时文件，用户第一次启动后自行填写模型信息；在已有 CDR 安装上执行安装时，目标目录已有的配置文件不会被发布包覆盖。
